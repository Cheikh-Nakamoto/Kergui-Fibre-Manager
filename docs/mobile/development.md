# Mobile app — development guide

Part of [the mobile app](README.md). How to build and work on the v1 app
(stand-alone, [RFC-004](../rfcs/RFC-004-standalone-mobile-app.md)).

## Stack

Baseline in October 2026; bump deliberately, one PR per major upgrade.

| Concern | Choice |
|---|---|
| Framework | **Expo SDK 58** (React Native 0.88, React 19.3, New Architecture) |
| Language | TypeScript 6, `strict` (TS 6 no longer loads `@types/*` implicitly: `types` in `tsconfig.json`) |
| Navigation | `expo-router`, routes in `src/app/` |
| Server state | `@tanstack/react-query` v5 — no optimistic router writes |
| Session | `zustand` + `expo-secure-store` |
| UI | `react-native-paper` (Material 3), `@expo/vector-icons` |
| Core | Go `mobilecore/` via `gomobile bind` + local Expo module `modules/kergui-core` |
| Tests | Jest (`jest-expo`), Maestro (demo mode) |
| Lint | ESLint 9 (`eslint-config-expo`) |
| Build / release | GitHub Actions: `expo prebuild` + Gradle / Xcode + fastlane — see [release-signing.md](release-signing.md) |

## Layout

```
mobilecore/                     Go composition root for the app (gomobile package)
mobile/
  app.json  app.config.js       name, ids (org.kergui.app), permissions, plugins, CI version numbers
  src/app/                      routes: index (welcome), connect, (tabs)/devices|wifi|settings, device/[mac]
  src/core/                     client.ts — the only code that calls the native module; types.ts
  src/features/queries.ts       React Query hooks per resource
  src/session/store.ts          session, vault key, demo mode
  src/i18n/                     fr.ts (all user-visible strings), t(), errorMessage()
  src/lib/ src/ui/              formatting, confirmation dialog, error banner
  modules/kergui-core/          Expo module: Kotlin + Swift bridge, android/libs/*.aar and ios/*.xcframework (generated)
  plugins/withReleaseSigning.js Android release signing from environment variables
  .maestro/demo.yaml            E2E flow (demo mode)
  fastlane/  Gemfile            iOS release lane
```

`android/` and `ios/` are generated by `expo prebuild` and not committed.

Layering: `src/app` → `src/features` → `src/core` → native module. Screens never
call the native module directly.

## Local workflow (Linux)

Needs Go (version from `go.mod`), Node 24, JDK 17+, the Android SDK with NDK
`28.2.13676358` (`ANDROID_HOME` set).

```sh
export ANDROID_NDK_HOME=$ANDROID_HOME/ndk/28.2.13676358
make mobile-core-android            # Go core → mobile/modules/kergui-core/android/libs/kergui-core.aar
cd mobile
npm ci
npx expo run:android                # prebuild + build + install on a device or emulator
```

The core is a native library: after changing Go code, rerun
`make mobile-core-android` and rebuild the app (Fast Refresh only reloads JS).
Expo Go cannot load it; use a development build (`expo run:*`).

- **Without a box**: tap "Essayer la démo" — the mock router runs inside the app.
- **With the box**: the phone on its Wi-Fi, "Connecter ma box", address
  `192.168.1.1` (https is tried first, then http).

iOS builds need macOS + Xcode: `make mobile-core-ios`, then `npx expo run:ios`.
From Linux, rely on the `ios` job of `mobile-ci.yml`.

## Checks

```sh
go test ./mobilecore/ ./internal/...     # core, demo flow, pinning, route allow-list
cd mobile && npx tsc --noEmit && npx expo lint && npx jest
maestro test .maestro/demo.yaml          # with the app installed on an emulator
```

## The bridge

The JS API (`modules/kergui-core/src/KerguiCoreModule.ts`) mirrors
`mobilecore.Core`: `open(vaultKey)`, `configure(url, adapterId, pin)`,
`request(method, path, body)`, `certificateFingerprint(url)`, `startDemo()`,
`stopDemo()`, `version()`. `request` answers like the dashboard's API
(`docs/api.md`); `src/core/client.ts` turns 4xx/5xx into `ApiError`
(`notSupported` for 501, `pinMismatch` for a changed certificate).

Adding an endpoint to the app: add its pattern to `routes` in
`mobilecore/core.go` (and a test), then a function in `src/core/client.ts`.

## Conventions

- Conventional commits (`feat(mobile): …`).
- No user-visible string outside `src/i18n/fr.ts`.
- Every router write goes through `confirm()` first.
- Use `npx expo install <pkg>` so versions match the SDK.
